# Constitution: ElectroCoach Bot

## Принципы кода

- **Простота MVP**: минимум абстракций, максимум скорости поставки. Не строим «на вырост».
- **Async-first**: весь I/O — асинхронный (aiogram, asyncpg, httpx).
- **Один файл — одна ответственность**: config, db, llm, session, bot — отдельные модули.
- **Секреты в .env**: никаких хардкодов токенов и ключей.

## Принципы продукта

- **Коуч, не советчик**: AI задаёт вопросы и отражает, не даёт советов.
- **Один вопрос за раз**: никогда не задавать пользователю 2+ вопроса в одном сообщении.
- **Атомарные сессии**: каждая сессия начинается с нуля, без памяти о прошлых.
- **Русский язык**: весь UX на русском.

## Качество

- Код должен запускаться с первого раза после `pip install -r requirements.txt`.
- Все edge cases из PRD обрабатываются промптом или кодом.
- Логирование ошибок LLM и БД — обязательно.

## Тестирование

- MVP: ручное тестирование через Telegram.
- Автотесты — вне скоупа MVP, но код должен быть тестируемым (чистые функции, DI).
