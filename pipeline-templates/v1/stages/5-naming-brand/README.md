# Stage 5 — Naming & Brand

## Цель

Назвать продукт, собрать брендовую платформу: словарь, стиль, ценностное позиционирование.

## Inputs

- PRD из Stage 4 (понимание «что»)
- Сегменты + value prop из Stage 2/4

## Prompts

Пошаговая рабочая тетрадь в 6 частях:

1. `01-brief.md` — бриф: аудитория, позиционирование, ограничения
2. `02-lexicon-diamond.md` — лексический diamond (категория → смежные → отдалённые → антиподы)
3. `03-explorations.md` — генерация кандидатов по нескольким направлениям
4. `04-criteria.md` — критерии отбора (Landor 8 principles, регистрируемость, произносимость)
5. `05-shortlist.md` — short-list 5–7 кандидатов с обоснованием
6. `06-finalists.md` — 2–3 финалиста, решение

## Outputs

- `results/naming-brief.md`
- `results/lexicon-diamond.md`
- `results/explorations/` — папка с batch'ами генерации
- `results/shortlist.md`
- `results/final-name.md` — финальное решение + brand-платформа
