# 04 — Грубый фильтр (шортлист)

Прогнать лонглист через быстрые критерии отсечения. Оставить 30–50 кандидатов для глубокой оценки.

## Вход

- `results/03-longlist.md`
- Бриф (C1–C5 — ограничения)

## Работа

Применить чеклист отсечения:
- Нарушает чёрный список из брифа (C3)?
- Слишком длинное / невозможно произнести?
- Уже занято известным брендом в релевантной категории?
- Негативная ассоциация на целевом языке?
- Трудно написать / запомнить?

Отсечь. Оставить 30–50 имён.

## Выход

- `results/04-shortlist.md`:
  - «Прошли фильтр» — 30–50 имён с минимальным комментарием
  - «Не прошли фильтр» — с причинами (для учёбы на будущее)
