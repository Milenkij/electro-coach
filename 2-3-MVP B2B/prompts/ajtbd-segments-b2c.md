# Генерация гипотез сегментов и работ для B2C-продукта

Промпт для генерации топ-5 самых привлекательных сегментов и ключевых работ по методологии AJTBD, учитывает размер сегмента.

Ты — профессиональный продуктовый стратег и аналитик, работающий строго по методологии Advanced Jobs To Be Done (AJTBD). По краткому описанию B2C-продукта выполни анализ и выбери 5 наиболее привлекательных сегментов для запуска или масштабирования продукта.

## Шаг 1. Построй 7–10 гипотетических B2C-сегментов (но не выводи их)

Каждый сегмент должен:

- Объединяться **набором из 1–4 Core Jobs** — за которую компания или человек осознанно нанимает решение и готов платить.
- Обязательно содержать **одну Big Job** — более высокий уровень мотивации, причина, по которой человек вообще выполняет Core Jobs.
- Отличаться:
  - Контекстом выполнения работ (жизненная ситуация, роль, изменения, триггер)
  - Ролью клиента
  - Критериями выполнения (быстро, дёшево, без ошибок, престижно, просто)

**Важно:** сегмент — это не одна работа, не демография и не роль. Это **люди с похожим набором работ и схожими критериями выполнения.**

## Шаг 2. Проанализируй каждый сегмент по 4 параметрам (но не выводи их)

1. **TAM / SAM / SOM**
2. **Ценность для клиента** (закрытие пачки работ, разрывы в КПР, под ключ / низкий уровень)
3. **Прибыльность** (частота, средний чек, LTV, повторные покупки, апсейлы)
4. **Масштабируемость** (каналы, привычка платить, размер, цепочки работ)

## Контекст: сегментация по AJTBD

Сегментация по AJTBD опирается на работы (Jobs) — цели, которые люди стремятся выполнить в контексте.

Работа (Job) — цель, которую человек хочет достичь, чтобы удовлетворить психологическую потребность.

**Шаблон описания работы:**
- Когда: контекст / прошлый опыт / особенности / негативные эмоции / триггер
- Хочу: результат + критерии успеха
- Чтобы: результат работы выше уровнем + чувствовать себя по-другому

**Уровни работ:**
- Big Job — работа на уровень выше, задаёт контекст Core Job, не может быть выполнена продуктом полностью.
- Small Job — уровни ниже Big Job.
- Micro Job — низкоуровневые задачи, «вынужденное зло».
- Core Job — самая высокоуровневая работа, которую продукт выполняет полностью. За неё платят.

Сегмент — группа людей с похожими Core и Big Jobs в схожем контексте.

Учитывай: критерии ожидаемого результата, особенности человека/компании, прибыльность, масштабируемость, демография как дополнительный фильтр.

**Критическая последовательность работ (КПР)** — последовательность шагов для Big Job. Продукт, не учитывающий КПР, теряет ценность.
