# Конкурентный анализ по графу работ

Граф конкурентов: для каждой из 11 работ из [ajtbd-analysis.md](ajtbd-analysis.md) перечислены решения, которые фаундер может нанять на эту конкретную работу. Номера в квадратных скобках — сквозные ссылки на справочник решений ниже.

**Обозначения:**
- **[★]** — работу полностью закрывает наш продукт
- **[⚡]** — работу частично усиливает наш продукт
- **[·]** — наш продукт к работе не нанимается напрямую

## Справочник решений (сноски)

**[1] BI / дашборды** — Tableau, Qlik, Yandex DataLens, Metabase, Google Sheets. Внутренние метрики, без внешнего нарратива. Фаундер видит цифры, не видит причин.

**[2] CFO / штатный финдиректор** — 500K–1,5M ₽/мес. Смотрит финансовый слой: P&L, юнит-эку, cash flow. Не смотрит команду, рынок, фаундера.

**[3] Совет директоров / инвесторы** — задают квартальные вопросы, требуют ответа от фаундера, но сами не диагностируют. Давление, не решение.

**[4] Со-фаундер** — внутренний партнёр. Разделяет со мной слепые зоны; может не хотеть ранить; тоже «внутри».

**[5] Industry-отчёты** — РБК, Kontur, Sensor Tower, Smart Ranking, TAdviser. Рынок «сверху», без привязки к конкретной компании.

**[6] Ментор / advisor из ближнего круга** — опытный предприниматель. 1 сессия в 2–4 недели. Тёплое общение, нет времени на погружение, даёт обобщённые эвристики.

**[7] Peer-группы** — Эквиум, YPO, Vistage, «Клуб первых», Atlasnet, Reforge, «500 Founders». Встречи 8–12 человек ежемесячно, 300K–2M ₽/год. Челлендж равных; пиры работают с моим описанием, не с моей компанией.

**[8] Executive coaching** — ICF-коуч, Hogan-практик, Leadership Circle. 1–2 сессии/мес по 1–1,5 часа. 30–100K ₽ за сессию, 300K–1,2M ₽ за год. Работает с состоянием фаундера, не с бизнесом.

**[9] Стратегический консалтинг** — Strategy&, EY-Parthenon, Co.Strategy, Strategy Partners, местные стратбутики. Проект 2–4 месяца, 5–30M ₽. Отчёт на 80–200 слайдов. Стадия + рынок; не команда и не фаундер; регулярности нет.

**[10] HR-консалтинг / organisational health** — Экопси, HT-Lab, SHL, AXES, Formatta, Talent Q. Проект 1,5–3 месяца, 1–8M ₽. Ассессмент, 360°, engagement survey. Только команда; не стадия, не рынок, не фаундер.

**[11] Fractional CFO** — 0,25–0,5 FTE, 150–400K ₽/мес. Финансовый слой на постоянной основе.

**[12] Fractional CMO / CSO** — 0,2–0,5 FTE, 300–700K ₽/мес. Рынок + воронка продаж.

**[13] Стратегическая сессия / фасилитатор** — Scaling Up (Verne Harnish), EOS (Gino Wickman), Rockefeller Habits, «Тайный Советник». Выезд 2–3 дня, 500K–3M ₽ за сессию. Мобилизация команды вокруг приоритетов; без регулярного мониторинга между сессиями.

**[14] MBA / executive education** — Сколково, ИМИСП, IMD, INSEAD EMBA. 1–2 года, 2–5M ₽. Расширение рамки и связи; не диагноз конкретной компании.

**[15] Психотерапия** — личный терапевт, 15–30K ₽/сессия. Личное состояние отдельно от бизнеса.

**[16] Self-help** — книги (Good to Great, Scaling Up, Measure What Matters), подкасты, YouTube, курсы. Рамки и чужой опыт; усиливает confirmation bias.

**[17] ChatGPT / Claude** — быстрый анализ текста. Нет данных компании, нет pulse команды, нет бенчмарков; фаундер сам описывает контекст с теми же искажениями.

**[18] Ничего не делать** — продолжать самому, ждать «ещё квартал». Сохраняет статус «я справляюсь», не решает работу.

**[19] Штатный Chief of Staff / strategy advisor** — 1 FTE, 500K–1,5M ₽/мес + опционы. 6–12 месяцев найма. Потенциально все 4 слоя, но: долго, заметно для команды и совета, зависимость от одного человека, быстро перестаёт быть «внешним».

**[20] Штатный HRD / CPO** — 1 FTE, 400K–1M ₽/мес. Команду глубоко и постоянно; не бизнес и не фаундер.

**[21] Внутренние спринты / OKR** — свой процесс мобилизации. Работает, если приоритет уже определён корректно.

**[22] Фасилитатор offsite / team-building** — разовая сессия синка для команды, 200K–800K ₽.

**[23] Fractional COO / Ops consultant** — 0,2–0,5 FTE, 300–700K ₽/мес. Эксплуатация изменений, процессы.

**[24] Fractional data-аналитик** — 150–300K ₽/мес. Построение метрик рычага, замер эффекта.

**[25] Публичные выступления / PR / контент** — внешний статус лидера через VC.ru, подкасты, Forbes-интервью, конференции.

**[26] Семья / супруг** — эмоциональная опора, нельзя «нанять» и «уволить».

**[27] Наш продукт** — «Второй взгляд» (150K, 3 дня) + квартальный контракт (300–500K ₽/мес). 4 слоя + связи + ежемесячный цикл + pulse команды в Telegram + квартальная стратсессия.

### Два кластера найма

**Кластер входа (W5 + W6):** снизить барьер пустить внутрь + дать полную картину за 3 дня.

**Кластер удержания (W7–W10):** челлендж решений + pulse + метрика эффекта + регулярный цикл.

### Где мы сильнее всего

- **W6** — выполняем работу целиком. Это продаёт «Второй взгляд».
- **W10** — выполняем работу целиком. Это продаёт квартальный контракт.

Остальные — усиливающие функции, не самостоятельные продажи.

### Где мы вообще не конкурируем

- **W3** (исполнение рычагов) — это не наша работа, мы показываем, куда ставить, не ставим за клиента.
- **W4** (ближний круг) — нельзя заменить со-фаундера или супруга.
- **W11** (восстановление статуса) — это побочный эффект работающего продукта, не наша услуга.

### Ключевой вывод для позиционирования

Ни один конкурент не даёт **одновременно** 4 слоя + связи + регулярно + быстро + незаметно + в зоне операционного решения. По каждому из этих параметров есть более глубокое, но одномерное решение. Мы нанимаемся на **пересечение всех шести параметров** на работах W6 и W10.
