## Придумайте идею продукта

На втором и третьем воркшопах вы будете делать MVP — от продуктовых требований до рабочего прототипа на сервере. Чтобы не тратить время на придумывание идеи на самом воркшопе — подумайте заранее.

**Требования к идее:**

- [ ] **Это веб-приложение** — не мобильное и не десктопное. Всё, что открывается в браузере: сайт, сервис, инструмент, личный кабинет, калькулятор, каталог — подходит.
- [ ] **Вам хочется это сделать** — вы будете работать с этим проектом несколько воркшопов. Если идея не зажигает — будет скучно.
- [ ] **Чем проще, тем лучше** — одна функция лучше, чем десять. Простой MVP вы доведёте до рабочего состояния, а сложный — нет.
- [ ] **Без сложных внешних интеграций** — на первых воркшопах вы делаете MVP без подключения внешних API. Если ваш продукт не работает без чужого сервиса — будет сложно. API подключим позже.
- [ ] **Можно протестировать самому** — вы будете запускать прототип и проверять его в браузере. Если для проверки нужны 10 пользователей или реальные данные из банка — это не подойдёт.

**Примеры не подходящих для интенсива идей:**
- Мобильное приложение для фитнеса (не веб)
- Маркетплейс с платёжной системой (слишком сложно для MVP)
- Агрегатор данных из 5 API (зависимость от внешних сервисов)
- Социальная сеть (нужны реальные пользователи для тестирования)

Не переживайте, если идея кажется маленькой. Маленькая идея, доведённая до рабочего продукта — лучше, чем грандиозная, которая осталась в голове.

## Что обязательно нужно установить и настроить преед стартом интенсива

Без этих пунктов дальше по курсу будет сложно двигаться. Сначала закрой их, потом переходи к остальным урокам.

- [ ] **VPN установлен и работает** (актуально для тех, кто в России)
  - Если доступ к [claude.ai](https://claude.ai) у тебя не ограничен — VPN не обязателен.
  - **Пройди гайд:** [Установка VPN](https://aura-framework.ru/guides/vpn-setup)
  - **Как проверить:** сайт `claude.ai` открывается без ошибок, можно войти в аккаунт.

- [ ] **Есть рабочий способ оплаты зарубежных сервисов**
  - **Пройди гайд:** [Оплата зарубежных сервисов](https://aura-framework.ru/guides/payments-foreign-services)
  - **Как проверить:** ты понимаешь, каким способом будешь оплачивать Claude Max и при необходимости другие сервисы.

- [ ] **Создан аккаунт Claude и оплачена подписка Max за $100**
  - **Пройди гайд:** [Регистрация Claude](https://aura-framework.ru/guides/claude-registration)
  - **Как проверить:** в профиле Claude указан активный план Max, можно отправлять сообщения в веб-интерфейсе.

- [ ] **Установлен Cursor**
  - Если уже пользуешься Cursor — этого достаточно. Если нет — установи его.
  - **macOS:** [Установка Cursor на macOS](https://www.aura-framework.ru/guides/cursor-install-mac)
  - **Windows:** [Установка Cursor на Windows](https://www.aura-framework.ru/guides/cursor-install-windows)
  - **Windows + Cursor:** чтобы **редактировать** файл `.md`, открывай его **двойным** кликом (один клик открывает превью).
  - **Как проверить:** ты можешь открыть любую папку с проектом и редактировать файлы.

- [ ] **Настроен Cursor для работы с Claude Code**
  - **Пройди гайд:** [Настроить внешний вид Cursor и подключить Claude Code](https://www.aura-framework.ru/guides/cursor-layout)
  - **Как проверить:** Ты можешь сделать запрос в Claude Code из курсор, видишь список файлов и можешь отредактировать файл 

- [ ] **Установлен Wispr Flow для голосового ввода**
  - **Пройди гайд:** [Wispr Flow](https://www.aura-framework.ru/guides/wispr-flow)
  - **Как проверить:** ты можешь зажать горячую клавишу, сказать фразу и увидеть, как текст появляется в любом поле ввода.

- [ ] **Понимаешь, как проверять лимиты Claude Code**
  - **Зайди на страницу:** [Claude Usage](http://claude.ai/settings/usage)
  - **Или выполни команду:** /usage в Claude Code 
  - **Как проверить:** в Claude Code команда `/usage` показывает текущее состояние лимитов.

- [ ] **Установлено расширение Claude в Chrome**
  - Пройди гайд: [Claude Chrome Extension](https://aura-framework.ru/guides/claude-chrome-extension)
  - **Как проверить:** в Chrome есть иконка Claude, боковая панель открывается, можно авторизоваться.

- [ ] **Установлен плагин Feature Dev в Claude Code**
  - Пройди гайд: [Установка плагина Feature Dev](https://aura-framework.ru/guides/ustanovka-i-zapusk-plagina-feature-dev)
  - **Как проверить:** при вводе `/feature-dev` в Claude Code появляется плагин и запускается диалог по разработке фичи.

- [ ] **Установлен Node.js**
  - **Пройди гайд:** [Установка Node.js](https://aura-framework.ru/guides/nodejs-install)

- [ ] **Установлено расширение Claude для Google Chrome**
  - **Пройди гайд:** [Установка и использование Claude в Chrome](https://aura-framework.ru/guides/claude-chrome-extension)

- [ ] **Получен доступ к вашему серверу на время обучения**
  - Зайдите в бота [@zamesin_boost_server_bot](https://t.me/zamesin_boost_server_bot) и сохраните себе куда-нибудь на компьютер данные доступа к серверу.
