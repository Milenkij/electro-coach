# Stage 1 — Discovery

## Цель

Зафиксировать гипотезу рана, контекст, допущения, первичные данные. На выходе — понимание «что исследуем и почему».

## Inputs

- Подписанная `constitution.md` из Stage 0
- Гипотеза из `meta.yml`

## Prompts

*(stubs — пайплайн v1 не фиксировал discovery в явном виде, будем дополнять в следующих ранах)*

## Outputs

- `results/00-initial-context.md` — контекст чата / письменной дискуссии, из которой вырос ран
- `results/hypothesis.md` — гипотеза в формате «если …, то …, потому что …»
- `results/assumptions.md` — допущения, которые предстоит проверить

## Methodology

- [GROW](../../../../knowledge/methodology/grow.md) — для структурирования разговора о цели
- [Дилтс — логические уровни](../../../../knowledge/methodology/dilts-logical-levels.md) — для углубления через уровни (окружение → поведение → способности → ценности → идентичность → миссия)
