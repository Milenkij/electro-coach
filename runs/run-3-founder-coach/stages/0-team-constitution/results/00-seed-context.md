# Stage 0 — Seed Context

## Состав рана

**Dyad:** Кирилл Миленкий + Алексей Шаповалов — бади по проекту, оба фаундеры.

## План Stage 0

1. **Founder-interview × 2** — каждый прогоняет второго по промптам [01-founder-interview.md](../prompts/01-founder-interview.md) и [02-founder-balance-wheel.md](../prompts/02-founder-balance-wheel.md). Cross-feedback: каждый формулирует обзор бизнеса / цели / ценности / компетенции / стоп-факторы другого, вторая сторона правит.
2. **Team-core-mapping (reduced)** — ролевая модель на двоих. Промпт [03-team-core-mapping.md](../prompts/03-team-core-mapping.md) адаптируется: вместо «ядра и расширения» — распределение функций между двумя фаундерами на ран (продюсер / делатель / контроль неопределённости).
3. **Team-interviews (skipped)** — нет подчинённых, стадия сворачивается в cross-feedback из п.1.
4. **Communication-assessment** — краткий чеклист: как синхронизируемся, где встречаемся, частота, эскалация при блоке.
5. **Constitution** — единый документ [constitution.md](constitution.md) (пока не создан), собирает п.1–4. Подписи обоих участников.

## Gating
