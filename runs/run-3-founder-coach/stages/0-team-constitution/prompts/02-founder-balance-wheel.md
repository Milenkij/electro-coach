# 02 — Колесо баланса фаундера

Визуализировать текущее состояние фаундера по 8 секторам жизни/работы. Цель — увидеть перекосы, которые могут повлиять на ран.

## Вход

- Выполнен `01-founder-interview.md` — есть понимание контекста фаундера

## Работа

1. Построить колесо из 8 секторов (0 → 10 по каждому):
   - Здоровье (физическое + ментальное)
   - Семья / отношения
   - Финансы (личные + бизнес runway)
   - Бизнес (текущее состояние)
   - Самореализация / смысл
   - Отдых / восстановление
   - Обучение / развитие навыков
   - Социальные связи / комьюнити

2. Для каждого сектора — оценка **прямо сейчас** (не «как хотелось бы»), одним числом + 1–2 предложения объяснения.

3. Найти:
   - Сектор с самой низкой оценкой (что блокирует?)
   - Сектор с самой высокой (на что опираться?)
   - Разрыв (max–min): если >5 — красная зона, ран может не выдержать
   - Секторы, прямо влияющие на ран (обычно: здоровье, финансы, бизнес, семья)

4. Записать 1–3 **красных флага**: что в текущем балансе может сорвать участие.

## Выход

- Файл `results/balance-wheel-<participant>.md`:
  - Таблица 8 секторов × оценка × комментарий
  - Разрыв max–min
  - 1–3 красных флага
  - Итог: «готов(а) / не готов(а) заходить в ран с таким балансом»
