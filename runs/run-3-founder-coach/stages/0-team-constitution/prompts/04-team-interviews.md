# 04 — Интервью с ключевыми сотрудниками

Проверить команду в действии: интервью с ключевыми людьми, которые заряжаются в ран на исполнительских ролях.

**Применимо только для рана с командой.** Для соло/dyad-рана — пропустить, явно отметить в `team-core-mapping.md`.

## Вход

- Выполнен `03-team-core-mapping.md`
- Определены ключевые сотрудники для интервью (обычно — закрывающие важные роли в ролевой модели)

## Работа

### 1. Назначить встречи, согласовать повестку

- Длительность: 45–60 минут на человека
- Формат: личная встреча или видеозвонок
- Заранее сообщить цель: «собираем команду под проект X, хочу понять твой контекст»

### 2. Провести интервью по блокам

**Блок A — текущая работа (10 мин)**
- Что сейчас делаешь в компании?
- Что получается / не получается?
- Что считаешь главным достижением последних 3 месяцев?

**Блок B — контекст рана (10 мин)**
- Слышал(а) ли про проект X? Что понимаешь о целях?
- Насколько тебе это интересно?
- Что беспокоит / что вдохновляет?

**Блок C — готовность (15 мин)**
- Сколько часов в неделю реально можешь выделить?
- Что придётся отложить ради этого? Ок ли с этим?
- Какие у тебя стоп-факторы (здоровье, семья, другие проекты)?
- Какая поддержка нужна (ресурсы, обучение, договорённости)?

**Блок D — честность (10 мин)**
- Что бы ты сказал(а) фаундеру, если бы знал(а), что это останется между нами?
- Видишь ли риски, которые фаундер не видит?
- Что бы ты сделал(а) иначе?

### 3. Оценить каждого сотрудника

По 4 параметрам (0–10):
- **Компетенция** — справится с ролью
- **Мотивация** — хочет заниматься этим
- **Вовлечённость** — есть ресурс (время, энергия)
- **Честность** — открыт в разговоре, не играет роль

## Выход

- По одному файлу на каждого сотрудника: `results/team-interview-<name>.md`
- Сводный файл `results/team-interviews-summary.md`: таблица с оценками по 4 параметрам + рекомендация «брать / не брать в ран / брать под условием»
