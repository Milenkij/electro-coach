## SQL-запросы (для воспроизведения)

```sql
-- Соло vs групповые
SELECT
  COUNT(*) FILTER (WHERE participant_count = 1) AS solo,
  COUNT(*) FILTER (WHERE participant_count > 1) AS group_sess,
  COUNT(*) AS total
FROM sessions;

-- Детали групповых
SELECT id, participant_count, participants, started_at, completed_at,
       status, rating, message_count
FROM sessions WHERE participant_count > 1
ORDER BY started_at DESC;

-- По пользователям
SELECT u.first_name, u.username,
       COUNT(s.id) FILTER (WHERE s.participant_count = 1) AS solo,
       COUNT(s.id) FILTER (WHERE s.participant_count > 1) AS group_sess,
       SUM(s.message_count) AS msgs
FROM users u LEFT JOIN sessions s ON s.user_id = u.id
GROUP BY u.id ORDER BY solo + group_sess DESC;
```
