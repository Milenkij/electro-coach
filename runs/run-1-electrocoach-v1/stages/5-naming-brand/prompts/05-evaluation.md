# 05 — Глубокая оценка

Прогнать шортлист через матрицу критериев (Landor 8 Principles) и качественные тесты. Сузить до 5–10 имён.

## Вход

- `results/04-shortlist.md`
- Бриф (для соотнесения с целями B1–B4)

## Работа

1. **Матрица критериев** — оценить каждое имя в шортлисте по 8 принципам Landor (читаемость, отличимость, значимость, запоминаемость, защитимость, расширяемость, глубина, гибкость) по шкале 0–5.
2. **Качественные тесты** для топ-10–15:
   - Тест заголовка (звучит ли в заголовке лендинга?)
   - Тест разговора («расскажи про <имя>» — естественно?)
   - Тест коллокации (с какими словами имя склеивается удачно?)
   - Тест границ (где имя ломается? регуляторика, язык, домен)

## Выход

- `results/05-evaluation.md`:
  - Матрица оценки (таблица: имя × 8 критериев × итоговый балл)
  - Качественные тесты для топ-10–15
  - Сузить до 5–10 имён для следующего шага
