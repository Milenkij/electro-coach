# 02 — Территории

Определить 5–8 смысловых территорий — метафорических пространств, из которых будем черпать имена. Территория — это направление поиска, а не само слово.

## Вход

- `results/01-brief.md`

## Работа

На основе брифа:
1. Предложить 5–8 территорий (название + метафора + 5–10 примеров слов-иллюстраций)
2. Получить обратную связь от пользователя: что добавить / убрать / приоритизировать
3. Зафиксировать финальный список с приоритетом (каждой территории — вес)

## Выход

- `results/02-territories.md`:
  - Финальный список территорий
  - Для каждой: название, метафора, примеры-иллюстрации (не финальные варианты!), приоритет
- Подтверждение пользователя
