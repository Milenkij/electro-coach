# 06 — Стресс-тест финалистов

Проверить 2–3 финалиста на защитимость, домены, регистрируемость, звучание в реальном контексте. Принять окончательное решение.

## Вход

- `results/05-evaluation.md` (с 5–10 именами после оценки)

## Работа

Для каждого финалиста (2–3 имени):
1. **Проверка доменов** — доступен ли `.com`, `.ru`, `.app`, `.ai` (по релевантности)
2. **Проверка ТМ** — открытые базы товарных знаков (РФ + США/ЕС по применимости)
3. **Проверка соцсетей** — заняты ли хэндлы
4. **Мокап заголовка лендинга** — реально посмотреть, как имя звучит в тизере
5. **Мокап разговора** — прогнать 3–5 сценариев: презентация инвестору, пост в соцсети, упоминание в подкасте, бренд-лайн

## Выход

- `results/06-finalists.md`:
  - По каждому финалисту — секция с проверками, мокапами, вердиктом
  - Итоговое решение: выбранное имя + 1–2 резерва
- Обновить `meta.yml` рана → зафиксировать выбранное имя
