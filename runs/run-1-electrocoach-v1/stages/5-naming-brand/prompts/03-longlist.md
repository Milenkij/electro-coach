# 03 — Генерация лонглиста

По каждой приоритетной территории сгенерировать 20–40 слов-кандидатов по методу Lexicon (ассоциации, морфемы, фонетика, метафоры).

## Вход

- `results/01-brief.md`
- `results/02-territories.md`

## Работа

1. Для каждой территории — генерация 20–40 вариантов (имена могут быть русскими, заимствованными, выдуманными — в рамках ограничений брифа C2).
2. Параллельно — собрать «слова от пользователя», которые пришли в голову вне территорий.
3. НЕ фильтровать на этом этапе — накопить массу для следующего шага.

## Выход

- `results/03-longlist.md`:
  - По каждой территории — блок с вариантами
  - Отдельный блок «Слова от пользователя (вне территорий)»
  - Общее число вариантов: 100–300
