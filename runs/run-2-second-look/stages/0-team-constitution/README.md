# Stage 0 — Team Constitution

## Цель

Зафиксировать команду, которая заряжается в ран. Ответить на вопросы: кто участвует, в каких ролях, с какими целями и стоп-факторами. Артефакт — «Конституция команды проекта». Без него ран не переходит в Stage 1.

## Inputs

- Факт существования рана (решение о начале, гипотеза)
- Люди, готовые участвовать

## Prompts

Запускаются последовательно, один за другим:

1. `00-founder-diagnostic-prep.md` — подготовиться к встрече с фаундером (повестка, компетенции ментора/ведущего, стоп-факторы).
2. `01-founder-interview.md` — обзор бизнеса, цели, ценности, компетенции, стоп-факторы. Для каждого участника-фаундера отдельно.
3. `02-founder-balance-wheel.md` — колесо баланса менторинга / фаундерских приоритетов.
4. `03-team-core-mapping.md` — ядро команды, минимальная ролевая модель (для dyad-ранов: ролевая модель на N участников).
5. `04-team-interviews.md` — интервью с ключевыми сотрудниками (для рана с командой; пропускается, если нет подчинённых).
6. `05-communication-assessment.md` — система коммуникаций (для рана с командой; пропускается для dyad).
7. `06-team-constitution.md` — сведение всех материалов в единый артефакт `constitution.md`.

## Outputs

- `results/constitution.md` — подписанный артефакт: участники, роли, цели, стоп-факторы, решение «едем»
- `results/founder-diagnostic-<participant>.md` — один на каждого фаундера
- `results/team-core-mapping.md` — ролевая модель (для dyad — на N человек; для рана с командой — с отдельными интервью)
- Опционально: `results/balance-wheel-<participant>.md`

## How to use

1. Если ран — **одиночный фаундер**: прогнать prompts 00–02 по себе, пропустить 03–05, написать constitution с одним участником.
2. Если ран — **dyad (2 фаундера без команды)**: prompts 00–02 × 2 участника (cross-interview), 03 в урезанной форме (ролевая модель на двоих), пропустить 04–05, свести в 06.
3. Если ран — **с командой**: все 7 prompts по методичке Клуба менторов.
4. В `meta.yml` выставить `constitution_artifact: stages/0-team-constitution/results/constitution.md`, `stage_0_status: signed`.
