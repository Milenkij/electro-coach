# Stage 0 — Historical Gap

Этот ран прошёл **до введения Stage 0** в пайплайн v1 (Stage 0 добавлен 2026-04-20 при реструктуризации репозитория в runs platform).

Ретро-заполнение не производится: артефакт «Конституция команды» имел бы смысл только в момент старта рана, а команда на старте была — соло-фаундер (Кирилл Миленкий), пивотирующий от Run 1 в B2B-направление.

Для минимального контекста участников рана — см. `runs/run-2-second-look/meta.yml` → поле `team`.

## Что могло бы быть здесь

- Founder-diagnostic по Кириллу (обзор бизнеса, цели, ценности, компетенции, стоп-факторы)
- Колесо баланса
- Constitution — что именно коммитилось на старте пивота (B2B-консалтинг, «Второй взгляд» + квартальный контракт)

Отсутствие этого артефакта — один из **learnings** перехода Run 1 → Run 2, зафиксированный в `/knowledge/learnings/b2b-eap-pivot-to-consulting.md`.
