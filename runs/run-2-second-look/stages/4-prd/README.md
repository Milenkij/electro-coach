# Stage 4 — Product Requirements Document

## Цель

Свести предыдущие 3 стадии в PRD: что делаем, для кого, с какими метриками, в каком scope.

## Inputs

- Сегменты + Core Jobs из Stage 2
- Данные рынка из Stage 3

## Prompts

- `prd-interview.md` — структурированное интервью для написания PRD (перенесено из Run 1)

## Outputs

- `results/PRD.md` — основной документ:
  - Проблема
  - Целевая аудитория (сегменты, AJTBD)
  - Value proposition
  - MVP scope (что делаем / что НЕ делаем)
  - Метрики успеха
  - Unit economics (если применимо)
  - Риски и допущения
