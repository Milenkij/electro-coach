# Принципы работы создателя Claude Code

**Дата:** 3 января 2026
**Автор:** Илья Измайлов (@ilia_izmailov)

---

Минутка супер полезного контента

Создатель Claude Code поделился своими принципами работы с клодом:

## Параллельная работа:
- Он работает в терминале в 5 окон с системой уведомлений, чтобы узнавать когда где-то нужен новый инпут
- Также он параллельно использует 5-10 вкладок в веб клоде

## CLAUDE.md:
Его команда использует общий CLAUDE.md. Каждый раз, когда они видят, что клод делает что-то не так, они добавляют правило в CLAUDE.md, чтобы это не повторилось

## Plan Mode:
Большую часть сессий он начинает с Plan mode

## Commands:
Они с командой активно используют commands, которые хранятся в `.claude/commands/` в git репозитории

## Hooks:
Он использует PostToolUse для форматирования кода после его написания

## Permissions:
Вместо `--dangerously-skip-permissions` он использует кастомные `/permissions`. Большая часть из них хранится в `.claude/settings.json` в git, то есть они общие на всю команду

## MCP интеграции:
Активно использует такие MCP, как Slack, BigQuery и Sentry

## Проверка работы:
Для очень долгих задач он просит Claude проверить свою работу с помощью фонового агента, когда он закончит, либо использует Stop-хук агента для более детерминированной проверки, либо использует плагин ralph-wiggum

## Chrome Extension:
Вероятно, самое важное для получения отличных результатов от Claude Code — дать Claude способ проверить свою работу. Если у Claude есть такая обратная связь, это в 2-3 раза повысит качество конечного результата. Claude тестирует каждое изменение, которое он вносит в claude.ai/code, с помощью Chrome-расширения. Claude открывает браузер, тестирует UI и итерирует, пока код не заработает.
