На этой неделе наконец нашёл время разобраться с плагинами в Claude Code — мой мир никогда не станет прежним

## Frontend разработка:
Базовый плагин от Anthropic уже круто бустит frontend разработку. Обычно нейросеть (без детального промпта) выдаёт типичный AI дизайн, который виден с первого взгляда. С плагином результаты гораздо лучше.

## Свои плагины:
Можно делать свои плагины под любые задачи. Например, я сделал плагин c книгой Вани Замесина, с помощью которого можно обсудить любой продукт в контексте AJTBD.

## Загруженные команды:
- Генерация идей по сегментам
- Тексты для лендинга
- Графы работ
- RAT анализ

Это всё можно вызывать в любом своём проекте, один раз установив этот плагин. Сам плагин я сгенерировал через Claude Code за 10 минут.

## Пять основных компонентов плагина:

### Commands
Добавляют пользовательские slash-команды, которые интегрируются в систему команд Claude Code.

### Agents
Специализированные субагенты для конкретных задач, которые Claude может автоматически вызывать при необходимости.

### Skills
Расширяют возможности Claude, вызываются моделью автономно на основе контекста задачи.

### Hooks
Обработчики событий, которые автоматически реагируют на события Claude Code (например, до/после использования инструмента, начало/конец сессии).

### MCP Servers
Подключают Claude Code к внешним инструментам и сервисам через Model Context Protocol. Например, к гугл таблицам или телеге.

## Примеры использования:

**Для не-разработчиков:**
- Плагин по книгам/статьям Ильяхова для редактирования текстов
- Загрузить книжек про продуктивность типа «Атомные привычки» и превратить нейросеть в коуча
- Юрист, загрузив туда нужного контекста

**Для разработчиков:**
- Хуки, которые срабатывают автоматически перед коммитом
- Команда `/test` — агент генерирует юнит-тесты, запускает их, видит ошибки, правит код и добивается зеленых тестов без участия
- Субагент для проверки кода на наличие уязвимостей
