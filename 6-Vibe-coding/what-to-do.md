### Задание 1: Строим бота поддержки «Золотого Яблока» (20 мин)

**Глоссарий:**
- **/feature-dev:feature-dev** — команда для пошаговой разработки. Claude сначала изучает задачу, проектирует архитектуру, а затем пишет код. Подходит для создания чего-то с нуля.
- **OpenRouter** — сервис, через который можно вызывать разные AI-модели (генерация текста, изображений и т.д.) через единый интерфейс. Каталог моделей: https://openrouter.ai/models

**Модель:** Opus

**Зачем:** Учимся создавать ботов поддержки с базой знаний — навык, который можно применить в любом проекте. А заодно осваиваем OpenRouter — сервис для подключения AI-моделей.

Сначала создайте бота в BotFather:
1. Откройте @BotFather в Telegram
2. Отправьте `/newbot`
3. Придумайте имя и username (username должен заканчиваться на `bot`, например `goldapple_support_bot`)
4. Скопируйте токен

Теперь запустите сборку через `/feature-dev:feature-dev`:

```
/feature-dev:feature-dev

Сделай Telegram-бота поддержки для интернет-магазина «Золотое Яблоко».

Бот отвечает на вопросы клиентов, используя базу знаний из файла data/goldapple-info.md.
Прочитай этот файл — там вся информация о доставке, возвратах, оплате, бонусах, подарочных картах и т.д.

Пользователь пишет вопрос → бот находит ответ в базе знаний → отвечает понятно и дружелюбно.

Важно: бот должен отвечать простым текстом, без markdown-разметки (без звёздочек, без списков с дефисами). В Telegram markdown не отображается и выглядит как мусор.

Токен бота: [вставьте токен из BotFather]

AI через OpenRouter API:
- Модель: google/gemini-3-flash-preview
- Ключ: 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

Собери и запусти.
```

**Что наблюдать:** `/feature-dev:feature-dev` сначала изучает задачу, проектирует архитектуру, а затем пишет код. Claude сам прочитает базу знаний, придумает как хранить и искать ответы, и соберёт бота. Вы не объясняете как кодить — только описываете что нужно.

**Что должно произойти:**
- Claude собрал бота и запустил
- Бот отвечает в Telegram на вопросы о Золотом Яблоке (доставка, возврат, оплата, бонусы и т.д.)

> **Хотите попробовать другую модель?** Каталог моделей: https://openrouter.ai/models — найдите модели с поддержкой текста и попросите Claude переключить.

### Задание 5: Создаём свою команду агентов для улучшения идей (15 мин)

**Глоссарий:**
- **Скилл** — команда Claude Code (вызывается через `/имя`). Файл с инструкциями: какую задачу решать, каких агентов создать, как они взаимодействуют. Хранится в `.claude/skills/`.
- **Агент** — файл с ролью для Claude. Описывает: что делает, как думает, с кем общается. Хранится в `.claude/agents/`.

**Модель:** Opus

**Зачем:** Вы научитесь создавать собственные команды агентов — это ключевой навык продвинутой работы с Claude Code. Вы получите переиспользуемую команду `/team-brainstorm`, которую можно скопировать в любой проект.

**Идея:** Как улучшить продукт? Можно думать самому, а можно запустить дебаты. Три агента: один генерирует идеи, а двое других спорят — пока один не примет сторону другого. Критик сдался — идея прошла. Адвокат сдался — идея отброшена.

**Сначала активируем команды агентов.** По умолчанию эта функция выключена — нужно включить её в настройках:

```
Добавь в настройки Claude Code переменную:
"CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS": "1"

Это нужно, чтобы заработали команды агентов — когда несколько AI-ролей работают вместе.
```

После этого **перезапустите Cursor** (закройте и откройте заново), чтобы настройки применились.

**Теперь создаём команду агентов:**

```
Создай команду агентов «Мозговой штурм» — для brainstorming'а улучшений продукта.

Это должна быть Agent Team — агенты, которые общаются между собой напрямую.
Адвокат отвечает на аргументы Критика, Критик отвечает на аргументы Адвоката.
Они ведут настоящий диалог, а не просто пишут по очереди.

Три агента:

1. Генератор — придумывает идеи улучшений. Смотрит на продукт
   и предлагает что можно добавить/изменить. По каждой идее —
   краткое описание и ожидаемый результат.

2. Адвокат — защищает идею. Объясняет почему она хорошая:
   польза для пользователя, простота реализации, wow-эффект.
   Если аргументы Критика сильнее — честно признаёт это.

3. Критик — атакует идею. Объясняет почему она плохая:
   сложность, риски, ненужность, лучше потратить время на другое.
   Если аргументы Адвоката сильнее — честно признаёт это.

Процесс:
1. Генератор предлагает идею
2. Адвокат аргументирует «за»
3. Критик аргументирует «против»
4. Адвокат и Критик спорят раунд за раундом,
   пока один не примет сторону другого:
   — Критик сдался → идея одобрена
   — Адвокат сдался → идея отброшена
5. Переходят к следующей идее
6. В конце — итоговый список: одобренные идеи с ключевыми аргументами

Сохрани всё на уровне проекта (в папке проекта).
Агентов — в .claude/agents/, скилл — в .claude/skills/team-brainstorm/SKILL.md.
Скилл вызывается командой /team-brainstorm.
```

**Что наблюдать:** Claude создаёт 3 файла агентов и 1 файл скилла. Откройте любой — увидите роль, инструкции, стиль мышления. Главное: в дебатах нет судьи — Адвокат и Критик спорят, пока один не сдастся. Это гарантирует, что слабые идеи не пройдут.

**Что должно произойти:**
- Созданы 3 агента в `.claude/agents/`
- Создан скилл `.claude/skills/team-brainstorm/SKILL.md`
- Скилл описывает: генерация → спор до победы одной стороны → итог

---

**Wow:** Вы только что создали свою команду AI-агентов. Три файла с ролями — и у вас есть инструмент для улучшения любого продукта.
