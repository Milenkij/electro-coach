# Business Model Canvas — рабочее пространство

Автономный набор канвасов Остервальдера. **Не связан** с `pipeline-templates/`, `runs/` или `knowledge/` — работает отдельно от основного пайплайна.

## Как пользоваться

1. Методология и шаблон — в [SKILL.md](SKILL.md).
2. Новый канвас — создать файл `canvases/<name>.md` (kebab-case, один файл = один канвас).
3. Имя файла отражает предмет канваса: продукт, гипотеза, сегмент или конкурент (например `electrocoach-b2c.md`, `competitor-airbnb.md`, `pivot-v2.md`).

## Структура

```
business-model/
├── README.md           — этот файл, индекс канвасов
├── SKILL.md            — скил Business Model Canvas (методология + шаблон)
└── canvases/           — заполненные канвасы
```
