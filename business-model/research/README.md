# Research — рыночные исследования по гипотезам пивота

Каталог содержит исследования (web research) по гипотезам, рассматриваемым в канвах `business-model/canvases/`.

## Зачем

В стадии 4 канвы возникают гипотезы пивота с предварительными оценками агента. Эти оценки — интуиция на основе известного материала. Чтобы решение было обосновано данными, по каждой гипотезе делается отдельное research-исследование (web-поиск, статистика, кейсы, конкуренты, бенчмарки). Результаты ложатся сюда.

## Конвенция именования

`h<номер-гипотезы>-<краткое-имя>.md`
