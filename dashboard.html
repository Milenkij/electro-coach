Сильные и слабые стороны

Сильные стороны

  • + Контрактинг работает — цель + тайминг в начале сессии
  • + Уровни Дилтса выявляют реальные блокеры
  • + Хорошо обрабатывает «не знаю» — переформулирует, упрощает
  • + Адаптирует глубину под юзера — коротко для Alexey, развёрнуто для darik
  • + Держит режим вопросов по коучинговой методологии
  • + Работает для неожиданных кейсов (бизнес, бессонница, горе)

Слабые стороны

  • ! «Я правильно понял?» в 40–75% сообщений бота (56 раз всего)
  • ! Ошибки с полом — мужской род для женщин («ты не выпал»)
  • ! Перегруз вариантами — 7–9 вместо 3–4
  • ! 80% сессий не закрыты — нет напоминания про /stop и оценку
  • ! Ломает коучинг на бизнес-вопросах (дрифт в режим советника)
  • ! Ранний баг: у Кирилла сессия 1 — 0 сохранённых сообщений бота
