# Обзор Opus 4.5

**Дата:** 27 ноября 2025
**Автор:** Илья Измайлов (@ilia_izmailov)

---

Погонял новый Opus на своих проектах с приличной кодовой базой — мне нравится

## Впечатления:
Работает быстро, галлюцинаций минимум. Прикрутил ИИ бота в поддержку сообщества VK за один промпт, предварительно подготовив спецификацию.

## Работа с API:
При работе с внешними API часто бывают проблемы, а тут он умудрился нагуглить правильную документацию, несмотря на блокировки ботов со стороны vk.

## Вывод:
Плюс один повод апгрейдиться до Claude Code Max.

---

**Релиз (25 ноября):**

Anthropic релизнули Opus 4.5 — по бенчмаркам лучшую модель для кодинга

Прошлыми опусами я не пользовался, потому что они были жуть какими дорогими. Opus 4.5 сделали аж в 3 раза дешевле прошлой версии, что не может не радовать.

В Claude Code, кстати, по обычной подписке Pro он по-прежнему недоступен — нужна подписка за $100 или $200. Также можно сделать депозит на баланс и попробовать Opus на Pro по цене API, но будет дорого.
