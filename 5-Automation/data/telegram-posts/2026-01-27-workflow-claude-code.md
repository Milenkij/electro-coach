# Подход к работе над новыми фичами в Claude Code

**Дата:** 27 января 2026
**Автор:** Илья Измайлов (@ilia_izmailov)

---

С опытом пришёл к такому подходу работы над новыми фичами в Claude Code:

1. **Не понимаю как делать** → `/deep-thinking` → получаю декомпозицию задачи и варианты решений

2. **Примерно понимаю как делать** → `/feature-dev` → он задает вопросы и предлагает 2-3 варианта архитектуры

3. **Понимаю как делать большую фичу** → врубаю plan mode → он детализирует задачу, показывает план и сохраняет его (что помогает сохранить его при compact)

Ещё есть `/brainstorm`, которым я особо не пользуюсь, но вдруг кому-то такое нравится — он задаёт очень много вопросов для детализации задачи

В командах ссылки на плагины в гитхабе, через которые их можно установить, так что берите на вооружение
