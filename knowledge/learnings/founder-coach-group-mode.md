**Seed-learning**, зафиксированный на старте Run 3. Дополняется по ходу рана.

## Контекст

Из AJTBD-анализа Run 2 всплыла гипотеза, что ElectroCoach применим не только лично фаундеру, но и как **инструмент групповой фасилитации**:
- Фаундер ведёт сессию с сооснователями / топами / партнёрами
- AI ассистирует в роли «в ухе у фаундера» — помогает держать структуру GROW/Дилтса, задавать правильные вопросы, не скатываться в защиту

## Ключевой инсайт

Персональное использование фаундером — **не prerequisite для группового**, а **параллельная точка входа**.

По данным ~15% — третий путь: «персональное в служении групповому» (фаундер тренируется на себе, чтобы качественно вести других).

Это переворачивает модель онбординга: не нужно делать из фаундера лояльного персонального пользователя, чтобы продать групповую фасилитацию. Это две независимые воронки, которые могут быть связаны, но не обязаны.

## Что проверять в Run 3

- Реальный спрос на групповой режим vs персональный — у кого и в каких ситуациях
- «AI в ухе» vs «нейтральный фасилитатор» — какой формат защитимее
- Что монетизировать в первую очередь — подписку персональную, сессию групповую, или пакет?

## Лимитации этого learning

- Основано на AJTBD-графе, который сам по себе — модель, не натурный эксперимент
- 15% — оценочная цифра из кластеров, не измеренная доля рынка
- Требует валидации на живых фаундерах, не только на гипотезе
