## Решение

Новый ран **не переходит в Stage 1 (Discovery)**, пока не закрыт артефакт Stage 0 — `constitution.md` («Конституция команды проекта»).

## Почему жёсткое гейтирование

- Без команды, утверждённой на старте, ран рискует **развалиться на полпути**. Опыт Run 1 и Run 2 (оба без Stage 0) — исторический gap, зафиксированный в STUB.md
- Stage 0 реализует принцип 2 Метода параноика («гибкие проектные команды»), см. [paranoid-as-governing-methodology.md](paranoid-as-governing-methodology.md)
- Соло-ран тоже должен пройти Stage 0 — это self-diagnostic, не бюрократия

## Что считается «закрытым Stage 0»

Артефакт `stages/0-team-constitution/results/constitution.md` содержит:

1. Кто в ране (список участников с ролями)
2. По каждому участнику — результат founder-diagnostic (обзор / цели / ценности / компетенции / стоп-факторы / колесо баланса)
3. Ролевая модель команды (кто продюсер, кто проджект-раннер, кто исполнитель)
4. Коммуникационный чеклист (частота, канал, эскалация)
5. Подписи участников (комбо фамилия + дата)

## Формы Stage 0 по размеру команды

| Состав | Формат |
|---|---|
| Соло-фаундер | Self-diagnostic: один проходит все 7 промптов на себе |
| Dyad (2 founders) | Cross-diagnostic: каждый ведёт второго; team-interviews swap на cross-feedback |
| Фаундер + малая команда (3–8) | Founder-diagnostic + team-core-mapping + interview с ключевыми людьми |
| Корп-ран (8+) | Полный формат всех 7 промптов |

## Для исторических ранов

Run 1 и Run 2 прошли **до введения Stage 0**. Ретро-заполнение не производится; вместо артефакта — [STUB.md](../../runs/run-1-electrocoach-v1/stages/0-team-constitution/results/STUB.md) с пометкой «historical gap».

## Что это даёт

- Прерывание плохих ранов на старте, а не посередине
- Формальное подтверждение команды — защита от «я думал, что ты это возьмёшь»
- Материал для ретро: после freeze рана есть с чем сравнить «что шло по конституции, что — нет»
