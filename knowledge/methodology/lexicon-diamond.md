Фреймворк Lexicon Branding для раскладки имени по осям смысла. Применяется на шаге «Территории» naming playbook.

## Оси

- **Sound** — звучание (звукосимволизм, ритм, энергия)
- **Meaning** — смысл (прямой, переносный, ассоциативный)
- **Association** — с чем склеивается (категория, эмоция, история)
- **Structure** — устройство слова (корни, морфемы, новообразование vs реальное слово)

## Использование в пайплайне

На шаге 2 naming playbook генерируются 6–10 «территорий» — разных сочетаний акцентов по этим осям. Каждая территория даёт свой набор кандидатов на шаге 3 (лонглист).
