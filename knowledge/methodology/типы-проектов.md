Классификация из «Метода параноика». Проекты различаются по типу главной неопределённости.

## Три типа

### Мозги (brain)

- Главная неопределённость — **как вообще решать**; задача требует оригинального мышления
- Нужны люди, которые умеют думать в неструктурированной среде
- Примеры: новый продукт, исследование, сложный пивот
- **Run 1, Run 2, Run 3 — все в категории Мозги**, поскольку это эксперименты с гипотезами

### Седина (grey hair)

- Неопределённость — **в опыте**; известно, как решать, но нужна насмотренность
- Нужны люди, кто делал это 10 раз и знает подводные камни
- Примеры: интеграция enterprise-продуктов, миграция БД под нагрузкой

### Процедуры (procedures)

- Неопределённость минимальна; главное — **не делать глупых ошибок**
- Нужна дисциплина и регламенты
- Примеры: выпуск очередного релиза, бухгалтерия, SLA-сопровождение

## Инверсный формат оценки

Оценивать проект нужно **от типа команды**, а не только от задачи:

- Если команда — «Процедуры», а задача — «Мозги»: будет долго, больно, потенциально нерешаемо
- Если команда — «Мозги», а задача — «Процедуры»: дорогая скука, люди разбегутся
- Правильное сочетание: тип команды ≥ тип задачи

## Применение в runs platform

В Stage 0 (Team Constitution) команда рана оценивает, соответствует ли их тип текущей гипотезе. Для «Мозгов» — нужны founder-диагностики и сверка ценностей; для «Процедур» — достаточно ролевой модели.
