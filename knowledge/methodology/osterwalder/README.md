# База знаний: Остервальдер и Пинье — «Построение бизнес-моделей»

**Источник:** Остервальдер А., Пинье И. «Построение бизнес-моделей: Настольная книга стратега и новатора», Альпина Паблишер, 2012 (ориг. Wiley, 2010).

**Назначение:** справочная методология по шаблону бизнес-модели (Business Model Canvas). Используется скилом `business-model/SKILL.md` и любыми другими скилами/сессиями, где нужны определения, типологии и правила работы с канвой.

## Как пользоваться

- **Один файл на один раздел книги.** Содержание каждого файла — правила и определения, не копия текста. Примеры — ссылочно, с отсылкой к странице в PDF.
- **Формат каждого файла:** TL;DR (5–10 строк) → концепты → правила → probing-вопросы.
- **Ссылки из скилов:** в `business-model/SKILL.md` и других скилах — ссылка на конкретный файл, а не пересказ.

## Что за рамками книги Остервальдера

Книга Остервальдера — методология 2010 года. Следующие добавления из других источников и из практики расширяют скил:

**Из книги Гассмана «Бизнес-модели: 55 лучших шаблонов»:**
- **55 паттернов бизнес-моделей** — [10-patterns-55.md](10-patterns-55.md). Расширяет 5 стилей Остервальдера.
- **6 мифов** на старте дизайна — [11-myths.md](11-myths.md).
- **Волшебный треугольник** (КТО / ЧТО / КАК / ПОЧЕМУ) для классификации инноваций — [04-strategy.md](04-strategy.md), §6.
- **10 рекомендаций по применению** — [12-implementation-checklist.md](12-implementation-checklist.md).

**Из практики наших сессий:**
- **Диагностический режим** заполнения канвы (interview-driven) — подход, полезный для «как есть» вместо «как должно быть». Живёт в `business-model/SKILL.md`.
- **Типология блокировок** у основателя (убеждения / избегание / нехватка навыка) — [07-blockers.md](07-blockers.md).
- **Cross-block сверка чисел** как обязательный шаг после блоков 5, 6, 9 — [08-reconciliation.md](08-reconciliation.md).
- **Post-canvas SWOT** с выгрузкой в PDF — расширение раздела 2 в [04-strategy.md](04-strategy.md), раздел 5.
- **Ильяхов-стиль** упаковки + PDF-конвейер + HTML-дашборд — [09-packaging.md](09-packaging.md).
