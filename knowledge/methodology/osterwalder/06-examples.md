# Реальные примеры бизнес-моделей

**Источник:** книга, разные страницы. Раздел «Примеры» вынесен отдельно, чтобы 01–05 не разрастались.

## TL;DR

- Каждый пример показывает один или несколько паттернов из [02-styles.md](02-styles.md) или [04-strategy.md](04-strategy.md).
- Записи короткие: таблица 9 блоков + 1–2 строки контекста + страница в PDF для деталей.
- Часть кейсов разобрана развёрнуто в других файлах — здесь только ссылка.
- Netflix и Airbnb добавлены из практики, не из книги.

## Где брать дополнительные примеры

- **Книга, стр. 12–18** — портреты семи новаторов с короткими описаниями.
- **Книга, разделы «Стили» (стр. 50–98)** — для каждого стиля 1–3 кейса.
- **Книга, раздел «Стратегия» (стр. 200–215)** — голубой океан, множественные модели.
- **Книга, раздел «Метод» (стр. 216–233)** — кейсы по каждой стадии.
