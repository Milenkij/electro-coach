# Шаблон бизнес-модели — 9 структурных блоков

**Источник:** книга, стр. 20–49. Раздел «Шаблон».

## TL;DR

- Бизнес-модель описывает логику создания, доставки и захвата ценности.
- 9 блоков покрывают 4 сферы: клиенты, предложение, инфраструктура, финансы.
- Шаблон — визуальный холст, на котором блоки собираются в одну картину.
- Правая половина холста (клиенты, предложение, каналы, отношения, доходы) — ценность и эмоция.
- Левая половина (партнёры, деятельность, ресурсы, издержки) — эффективность и логика.
- Работа с шаблоном идёт на большом листе со стикерами, в команде.

## Определение

> Бизнес-модель служит для описания основных принципов создания, развития и успешной работы организации.

**Почему важно определение:** без общего языка обсуждение моделей переходит в спор о словах. Язык шаблона — одна из основных ценностей подхода.

**Четыре сферы, которые охватывают 9 блоков:**
1. **Клиенты** — потребительские сегменты, взаимоотношения.
2. **Предложение** — ценностные предложения.
3. **Инфраструктура** — каналы, ресурсы, деятельность, партнёры.
4. **Финансы** — потоки доходов, структура издержек.

## 9 блоков

### 1. Потребительские сегменты (ПС)

**Определение:** группы людей и организаций, которые предприятие рассчитывает привлекать и обслуживать.

**Ключевые вопросы:**
- Для кого мы создаём ценностное предложение?
- Какие клиенты для нас более важны?

**Критерии выделения отдельного сегмента (хотя бы один пункт):**
- Различия в запросах обусловливают различия в предложениях.
- Взаимодействие идёт по разным каналам сбыта.
- Разные типы взаимоотношений.
- Существенные различия по выгодности.
- Разные аспекты предложения их привлекают.

**Типы сегментов:**

| Тип | Описание | Пример |
|---|---|---|
| **Массовый рынок** | Нет различий между сегментами | Бытовая электроника |
| **Нишевый рынок** | Особый сегмент; ценностное предложение и каналы построены под нишу | Поставщики автомобильных деталей |
| **Дробное сегментирование** | Сегменты отличаются незначительно, но требуют разного предложения | Credit Suisse: клиенты с вкладами >$100k и >$500k |
| **Многопрофильное (диверсифицированное) предприятие** | Два и более не связанных сегмента | Amazon: розница + облачная служба |
| **Многосторонние платформы** | Два или более взаимосвязанных сегмента, нужны оба | Кредитные карты: держатели + торговые точки; бесплатная пресса: читатели + рекламодатели |

### 2. Ценностные предложения (ЦП)

**Определение:** совокупность товаров и услуг, которые представляют ценность для определённого сегмента.

**Ключевые вопросы:**
- Какие ценности мы предлагаем потребителю?
- Какие проблемы помогаем решить?
- Какие потребности удовлетворяем?
- Какой набор товаров и услуг предлагаем каждому сегменту?

**Виды ценности:**

| Вид | Описание |
|---|---|
| **Новизна** | Удовлетворение потребностей, которых раньше не существовало (мобильные телефоны, этичные инвестфонды) |
| **Производительность** | Повышение эффективности знакомого продукта |
| **Изготовление на заказ** | Подгонка под индивидуальные запросы + сохранение экономии на масштабе |
| **«Делать свою работу»** | Выполнение работы клиента за него (Rolls-Royce обслуживает двигатели, авиалинии платят за час работы) |
| **Дизайн** | Трудно измеряется, критичен в моде и бытовой технике |
| **Бренд/статус** | Ценность использования конкретного бренда (Rolex, андеграундные марки) |
| **Цена** | Та же выгода по меньшей цене. Порождает FREE-модели — см. `02-styles.md` |
| **Уменьшение расходов** | Snижение расходов клиента (Salesforce.com — CRM без установки) |
| **Снижение риска** | Гарантии, сертификации, SLA |
| **Доступность** | Услуги для ранее отсечённых групп (NetJets — долевое владение частными самолётами) |
| **Удобство / применимость** | Простота использования (iPod + iTunes) |

### 3. Каналы сбыта (КС)

**Определение:** система взаимодействия компании с потребителем для донесения ценностного предложения.

**Ключевые вопросы:**
- Какие каналы взаимодействия желательны?
- Как взаимодействуем сейчас?
- Как связаны каналы между собой?
- Какие наиболее эффективны? Какие более выгодны?

**Функции канала:**
- Повышают осведомлённость о товарах и услугах.
- Помогают оценить ценностное предложение.
- Позволяют приобрести.
- Знакомят с ценностными предложениями.
- Обеспечивают постпродажное обслуживание.

**Пять этапов канала:**

| Этап | Содержание |
|---|---|
| 1. Информационный | Как повышаем осведомлённость? |
| 2. Оценочный | Как помогаем клиенту оценить ценностное предложение? |
| 3. Продажный | Как продаём? |
| 4. Доставка | Как доставляем ценностное предложение? |
| 5. Постпродажный | Как обеспечиваем поддержку после продажи? |

**Классификация каналов:**

|   | Прямые | Непрямые |
|---|---|---|
| **Собственные** | Торговые агенты, интернет-сайт | Фирменные магазины |
| **Партнёрские** | — | Партнёрские магазины, оптовики |

**Правило баланса:** партнёрские каналы дают меньшую прибыль, но больший охват. Собственные прямые — больше прибыли, но дороже в управлении. Ищи сочетание, которое даёт максимальный доход и лучшие отзывы потребителей.

### 4. Взаимоотношения с клиентами (ВК)

**Определение:** типы отношений, которые компания устанавливает с сегментами.

**Ключевые вопросы:**
- Отношений какого типа ждёт каждый сегмент?
- Какие отношения установлены?
- Каких расходов они требуют?
- Как они интегрированы в общую схему?

**Мотивы построения отношений:**
1. Приобретение клиентов.
2. Удержание клиентов.
3. Увеличение продаж.

**Типы отношений:**

| Тип | Описание |
|---|---|
| **Персональная поддержка** | Личные контакты на месте продажи, в колл-центре, по почте |
| **Особая персональная поддержка** | Конкретный представитель прикреплён к конкретному клиенту (private banking) |
| **Самообслуживание** | Нет прямых отношений; компания даёт средства |
| **Автоматизированное обслуживание** | Сочетание самообслуживания и автоматизации (рекомендации книг, фильмов) |
| **Сообщества** | Онлайн-сообщества, в которых участники обмениваются знаниями (alli от GlaxoSmithKline) |
| **Совместное создание** | Клиент создаёт ценность вместе с компанией (Amazon — рецензии, YouTube — контент) |

### 5. Потоки поступления дохода (ПД)

**Определение:** материальная прибыль, которую компания получает от каждого сегмента. Чистая прибыль — после вычета издержек.

**Ключевые вопросы:**
- За что клиенты действительно готовы платить?
- За что платят сейчас?
- Как платят?
- Как предпочли бы платить?
- Какую часть общей прибыли приносит каждый поток?

**Два типа потоков:**
1. Разовые сделки.
2. Регулярные поступления (периодические платежи за ценностное предложение или постпродажное обслуживание).

**Способы создания потоков:**

| Способ | Описание | Пример |
|---|---|---|
| **Продажа активов** | Права собственности на материальный продукт | Amazon, Fiat |
| **Плата за использование** | Чем больше пользуется, тем больше платит | Мобильная связь, отель, курьер |
| **Оплата подписки** | Продажа длительности доступа | Тренажёрный зал, World of Warcraft, Nokia Comes with Music |
| **Аренда/рента/лизинг** | Временные права на пользование | Zipcar |
| **Лицензии** | Передача прав на интеллектуальную собственность | Медиа, технологии |
| **Брокерские проценты** | Посредничество между двумя сторонами | Кредитные карты, недвижимость |
| **Реклама** | Оплата рекламы товара, услуги или марки | СМИ, игровая индустрия |

**Механизмы ценообразования:**

| Фиксированные цены (статические переменные) | Свободные цены (меняются по рынку) |
|---|---|
| По прейскуранту | Договор между партнёрами (торги) |
| Зависимость от характеристик продукта | Управление доходами (номера в отелях, авиабилеты) |
| Зависимость от сегмента | Торговля в реальном времени (уровень спроса и предложения) |
| Зависимость от величины закупки | Аукцион |

### 6. Ключевые ресурсы (КР)

**Определение:** наиболее важные активы, необходимые для функционирования бизнес-модели.

**Ключевые вопросы:**
- Какие ключевые ресурсы нужны для наших ценностных предложений? Каналов сбыта? Взаимоотношений с клиентами? Потоков доходов?

**Категории ресурсов:**

| Категория | Описание | Пример |
|---|---|---|
| **Материальные** | Физические объекты: производственные мощности, здания, оборудование, сети дистрибуции | Wal-Mart, Amazon |
| **Интеллектуальные** | Торговые марки, закрытая информация, патенты, авторские права, базы данных | Nike, Microsoft, Qualcomm |
| **Персонал** | Кадры в наукоёмких и творческих отраслях | Novartis — штат учёных |
| **Финансы** | Денежные средства, кредитные линии, фондовый резерв | Ericsson — гарантии для заказчиков |

**Кому принадлежат ресурсы:** собственность компании, наём, ключевые партнёры.

### 7. Ключевые виды деятельности (КД)

**Определение:** действия компании, необходимые для реализации бизнес-модели.

**Ключевые вопросы:**
- Каких видов деятельности требуют наши ценностные предложения? Каналы сбыта? Взаимоотношения с клиентами? Потоки доходов?

**Категории:**

| Категория | Описание | Пример |
|---|---|---|
| **Производство** | Разработка, создание, вывод продукта на рынок | Компании-производители |
| **Разрешение проблем** | Поиск решений конкретного клиента; управление знаниями и отработка навыков | McKinsey, больницы |
| **Платформы/сети** | Управление, сервисное обеспечение и продвижение платформ | eBay, Visa, Microsoft Windows |

### 8. Ключевые партнёры (КП)

**Определение:** сеть поставщиков и партнёров, благодаря которым работает бизнес-модель.

**Ключевые вопросы:**
- Кто наши ключевые партнёры?
- Кто основные поставщики?
- Какие ключевые ресурсы получаем от партнёров?
- Какой деятельностью занимаются наши партнёры?

**Четыре типа партнёрских отношений:**
1. Стратегическое сотрудничество между неконкурирующими компаниями.
2. Соконкуренция — стратегическое партнёрство между конкурентами.
3. Совместные предприятия для запуска новых проектов.
4. Отношения производителя с поставщиками.

**Три мотива партнёрств:**

| Мотив | Что даёт |
|---|---|
| **Оптимизация и экономия в производстве** | Снижение издержек через аутсорсинг и совместное использование инфраструктуры |
| **Снижение риска и неопределённости** | Стратегические союзы (Blu-ray) |
| **Поставки ресурсов и совместная деятельность** | Получение знаний, лицензий, доступа к потребителю |

### 9. Структура издержек (СИ)

**Определение:** расходы, связанные с функционированием бизнес-модели.

**Ключевые вопросы:**
- Какие наиболее важные расходы предполагает наша бизнес-модель?
- Какие ключевые ресурсы наиболее дороги?
- Какие ключевые виды деятельности требуют наибольших затрат?

**Два класса моделей по подходу к издержкам:**

| Класс | Описание | Пример |
|---|---|---|
| **Ориентация на издержки** | Минимизация издержек, дешёвые ценностные предложения, максимальная автоматизация, широкое привлечение сторонних ресурсов | Дешёвые авиаперевозчики: Southwest, easyJet, Ryanair |
| **Ориентация на ценность** | Создание премиальной ценности, высокий личный сервис | Роскошные отели |

**Большинство моделей находятся между двумя крайностями.**

**Категории издержек:**

| Категория | Описание |
|---|---|
| **Фиксированные** | Не зависят от объёма (зарплаты, аренда, средства производства) |
| **Переменные** | Зависят от объёма (материалы, аренда площадок для фестивалей) |
| **Экономия на масштабе** | Снижение издержек на единицу за счёт объёма |
| **Эффект диверсификации** | Одни и те же каналы или маркетинг для разных продуктов |

## Шаблон — визуальное представление

**Форма шаблона (слева направо, сверху вниз):**

```
| КП | КД | ЦП | ВК | ПС |
|    | КР |    | КС |    |
| СИ     | ПД              |
```

Где:
- КП — ключевые партнёры
- КД — ключевые виды деятельности
- КР — ключевые ресурсы
- ЦП — ценностные предложения (центр)
- ВК — взаимоотношения с клиентами
- КС — каналы сбыта
- ПС — потребительские сегменты
- СИ — структура издержек
- ПД — потоки поступления дохода

**Разделение холста:**
- **Правая половина (ПС, ВК, КС, ЦП, ПД) — ценность и эмоция.**
- **Левая половина (КП, КД, КР, СИ) — эффективность и логика.**

## Правила работы с шаблоном

1. **Большой формат.** Распечатать как можно больше, чтобы команда могла работать со стикерами и маркерами.
2. **Команда.** 60 первокурсников с нулём опыта за 5 дней собирают жизнеспособную идею (пример из книги). Шаблон рассчитан на групповую работу.
3. **Разнородная команда.** Смешивать роли и бэкграунды — в разделе `03-design.md` подробно.
4. **Стикеры, а не текст.** Каждый элемент — отдельный стикер. Стикеры переставляются, убираются, дополняются.
5. **Как минимум 2 версии:** «как есть» и «как должно быть». Разница — источник стратегии.
6. **Шаблон — язык, не план.** Нужен для общего обсуждения, сравнения, поиска альтернатив.
7. **Итерация.** Модель не фиксируется в первой версии. Прототипирование — отдельная техника, см. `03-design.md`.

## Где брать «отправные» вопросы

Ниже — probing-вопросы для первого прохода по блокам. Работают в команде, на интервью и в режиме диагностики:

| Блок | Главный вопрос |
|---|---|
| ПС | Кого обслуживаем? Кто самые важные клиенты? |
| ЦП | Какую ценность даём? Какие проблемы решаем? |
| КС | Каких каналов ждут клиенты? Как связаны каналы? |
| ВК | Какие отношения ждут клиенты? Какие установлены? |
| ПД | За что клиенты платят сейчас? За что предпочли бы платить? |
| КР | Какие ресурсы нужны для ценности, каналов, отношений, доходов? |
| КД | Какая деятельность нужна для ценности, каналов, отношений, доходов? |
| КП | Кто ключевые партнёры? Что получаем от них? |
| СИ | Какие расходы самые важные? Какие ресурсы и деятельность наиболее дороги? |
