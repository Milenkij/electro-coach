# КФБУ-индекс — оценка бизнес-модели по 20 ключевым факторам

**Источник:** методика Михаила Гребенюка (Resulting), презентация на Альфа-Конфе. Материалы: [пост в TenChat](https://tenchat.ru/media/2881192-vazhnost-strategii-v-biznese-i-podborka-iz-20-kfbu-insayty-s-alfakonfy), [статья на vc.ru](https://vc.ru/education/1714047-klyuchevoi-faktor-biznes-uspeha-kfbu-ot-mihaila-grebenyuka).

## TL;DR

- КФБУ = «параметры, по которым можно судить, насколько большой потенциал у бизнеса».
- 20 факторов. По каждому бинарная оценка: **соответствует +1 / не соответствует 0**. Сумма = индекс 0–20.
- Главный практический принцип Гребенюка: **«для масштабирования достаточно сделать так, чтобы факторов стало больше хотя бы на один»**. Прирост на +1 уже даёт ощутимый сдвиг.
- В нашей методологии — **последний шаг стадии 5** канвы (после финального вопроса). Закрепляет диагностику и даёт численную точку отсчёта для будущих ревизий.

## 20 КФБУ — полный список

| № | Фактор | Что значит |
|---|---|---|
| 1 | **Существование рынка** | Спрос в нише есть |
| 2 | **Рост рынка** | Растущий, не сжимающийся рынок (ИИ ✓, ремонт радиоприёмников ✗) |

## Методика подсчёта

1. Пройтись по каждому из 20 факторов.
2. Бинарно оценить: **1** (соответствует) или **0** (не соответствует).
3. Если ответ «частично» — округлять консервативно к 0, либо прописывать оба варианта (current = 0, target = 1) для отслеживания.
4. Сумма = индекс. Шкала 0–20.

**Важная оговорка автора:**
> «Все очень индивидуально и нельзя каждый бизнес адаптировать под все 20 КФБУ, но при должном анализе они очень пригодятся.»

Не каждый фактор обязателен. Цель — **видеть, где есть потенциал прироста**.

## Применение в нашей методологии

КФБУ-индекс — **последний шаг стадии 5** (Применение). Идёт после финального вопроса «что больше всего удивило». Логика:
- Стадии 1–4 описывают и оценивают модель.
- 5.1–5.3 формируют план действий.
- 5.4 — упаковка артефакта.
- 5.5 — рефлексия.
- 5.6 — **численный индекс как точка отсчёта.**

### Шаги в сессии

1. Прочитать список 20 КФБУ.
2. По каждому пункту — обсудить с пользователем и поставить 0/1.
3. Записать в раздел «Применение / КФБУ-индекс» канвы как таблицу с колонками: фактор / оценка / комментарий / приоритет улучшения.
4. Подсчитать сумму.
5. Выделить **3–5 факторов с самым простым приростом 0 → 1** на ближайшие 6–12 мес. Это input для следующих ревизий канвы.

### Использование при сравнении канв

- При сравнении as-is и to-be канв индекс показывает **квантитативный сдвиг** дизайна.
- Цель пивота — **прирост индекса минимум на +3** (по правилу Гребенюка «+1 уже даёт сдвиг», +3 — заметно).
